How it works

Five steps, every request

Night Watch sits in front of the bank's API as its gateway and reads its ledger, its Git and its CI. It never needs the attacker to make a mistake the human checks can see.

01

Detect

Scores each request against a profile learned from that customer's own 90-day history.

02

Decide

Allow, hold for a human, or block. Every point of risk has a reason a regulator can read.

03

Contain

Kill the session, revoke the API key, refuse the payment. Enforced in the bank, not on a slide.

04

Learn

From analysts' answers and from breaches: mule accounts, hostile networks, new gateway rules.

05

Fix with Devin

When the bank's own code was the hole, Devin gets the evidence and a failing test, and opens the PR.

What's real

A fictional bank. A real defense.

The bank is fictional. The defense is not: you can attack it from a terminal and watch it hold.

API

A live bank API

Oasis Bank: 12 customers, IBANs, balances and 1,920 statement lines. Blocked means a real 403 and money that did not move.

Profiles

Learned behaviour

Normal amounts, payees, hours, devices and countries come from history and keep updating with every allowed payment.

Ledger

Ledger invariants

After every request it checks the rules that must always hold. A violation means the bank's code has a bug, so it reverses the money.

Gateway

Virtual patches

A breach becomes a gateway rule in milliseconds, aimed at the exact request field that carried the attack.

CI

Code guard that reads code

An AST scanner compares every function before and after a pull request: removed checks, bypasses, secrets, egress.

Analyst

A human stays in charge

Analysts confirm or release. Each answer teaches it: blocklists grow, weights shift, false positives stop repeating.

Built with and run by Devin

Containing is fast. Fixing is engineering.

Night Watch never tells Devin the answer. It gives Devin what a senior engineer would want: the exact request, the invariant it broke, the function that served it, and a regression test replayed from the real attack that fails today. Devin finds the root cause, fixes it, and the PR only goes green when that test passes.
